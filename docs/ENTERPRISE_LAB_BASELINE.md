# 小微企业网络毕业设计基线

参考选题为「基于 eNSP 的小微企业网络规划与 ACL 访问控制设计」。任务书应写清部门、网络服务、允许与拒绝的访问关系、冗余方式，以及逐项验收依据。

## 一 网络规模

规划两台出口路由器、两台防火墙、八台交换机。八台交换机可采用双核心、双汇聚、四台部门接入。核心和汇聚使用独立设备及冗余上联，按设备支持情况选用 VRRP 与 MSTP 或等效机制。无线采用 AC 集中管理 AP，覆盖员工与访客两类终端。

出口路由器和防火墙均需设计主备及故障测试。防火墙的状态同步、现有 NAT 会话能否保留和切换时间分别实测。设备型号与镜像支持情况须在生成命令前确认。

## 二 设计范围

| 模块 | 任务要求 | 验收依据 |
|---|---|---|
| 无线接入 | AC 管理 AP。员工与访客使用两个加密 SSID，分别映射独立 VLAN | AP 注册、两种终端关联、正确的租约和隔离结果 |
| 部门划分 | 技术、行政、财务、销售、服务器、AP 管理分 VLAN。另设员工和访客无线 VLAN | 端口与 VLAN 对应、广播域和冗余链路状态 |
| DHCP | 有线终端、无线终端及 AP 自动取得相应网段的地址和网关 | 各类终端租约和 DHCP 状态 |
| 三层互通 | VLANIF 提供网关，按权限矩阵放行跨网段通信 | 接口状态、路由表和应通用例 |
| 分级访问 | 访客只访问模拟外网，拒绝企业内部网段。行政和销售禁止访问财务，技术可访问受管网段 | 每条权限至少有对应的允许或拒绝用例。记录测试方向与策略状态 |
| 出口 NAT | 企业内网经主用出口共享一个模拟公网地址 | NAT 转换记录、外网服务连通及主备切换后的新连接 |
| 静态路由 | 验证内网汇总、默认路由和外部返回路径 | 去程、回程和故障切换后的路由表与流量结果 |
| 接入端口安全 | 区分员工有线口和公共接入口，按机型能力配置授权终端或 MAC 约束 | 合规终端可用，额外接入的未登记终端受限 |
| 高可用 | 分别验证核心上联、出口路由器和防火墙故障 | 切换前后状态、恢复时间、连接影响及恢复后的复测 |

## 三 交付与证据

提交标有端口的拓扑、地址与权限矩阵、所有设备完整命令、AC 与 AP 的上线记录、用例输出和截图。记录每次故障切换的操作、观测时间和恢复结果。实验公网由隔离的模拟网段提供。计划和预期结果在任务书中列明，验收结论引用实际输出。
